# devlog 템플릿

## devlog 작성 항목
| 항목 | 내용 |
|---|---|
| **규칙** | devlog 작성 시 `작업 요약`, `주요 변경점 & 설계 결정`, `테스트 결과`, `다음 진행 작업` 4가지 필수 섹션 포함 |
| **이유** | 작업 세션 이력 보존 및 팀원/에이전트 간 맥락 연속성 유지 |
| **예시** | ## 작업 요약\n- HWPX 구조 Manifest Tool 추가 |
| **위반 시** | 필수 항목 누락 시 devlog 승인하지 않음 |

## devlog 저장 위치 및 공유
| 항목 | 내용 |
|---|---|
| **규칙** | 작성된 devlog는 `raw/dev-logs/` 원본 보존 후 ingest 프로세스를 통해 `wiki/devlog/`에 반영 |
| **이유** | 프로젝트 기억 유지 및 지속적인 브리핑 자료로 활용 |
| **예시** | `raw/dev-logs/2026-07-24-hwpx-manifest.md` |
| **위반 시** | 개인 로컬 임시 폴더에만 개발 기록 보관 금지 |

## 서식 규칙
| 항목 | 내용 |
|---|---|
| **규칙** | Markdown 개조식(Bullet point) 중심으로 명확하고 간결하게 작성 |
| **이유** | 빠른 가독성 확보 및 에이전트 분석 토큰 효율화 |
| **예시** | - `FastMCP` 서버 인스턴스 초기화\n- `inspect_document` 툴 등록 완료 |
| **위반 시** | 불필요한 장문의 수식어 사용 자제 |
