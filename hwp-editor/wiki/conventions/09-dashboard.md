# 대시보드 설정

## 대시보드 메인 구성 요소
| 항목 | 내용 |
|---|---|
| **규칙** | 대시보드(`wiki/dashboard.md`)의 최상단 핵심 정보로 `남은 TODO 및 마일스톤 작업`을 가장 우선하여 배치 |
| **이유** | 프로젝트의 현재 진행 상황과 즉시 해결해야 할 다음 작업 목록을 한눈에 파악하기 위함 |
| **예시** | ## 📌 남은 TODO\n- [ ] `rhwp` 렌더링 검증\n- [ ] FastAPI Control Plane 초안 작성 |
| **위반 시** | 남은 TODO 누락 시 대시보드 업데이트 불인정 |

## 대시보드 갱신 주기
| 항목 | 내용 |
|---|---|
| **규칙** | 주요 작업 세션 종료 시 또는 의미 있는 마일스톤 변경 후 `wiki/dashboard.md` 자동/수동 동기화 |
| **이유** | 최신 작업 현황의 투명한 보존 |
| **예시** | `/brief` 실행 시 대시보드 상태 함께 요약 |
| **위반 시** | 장기간 대시보드가 stale 상태로 방치되지 않도록 유효성 점검 |
