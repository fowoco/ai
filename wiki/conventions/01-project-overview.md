# 프로젝트 개요

## 프로젝트 목적
| 항목 | 내용 |
|---|---|
| **규칙** | 로컬 HWPX 문서의 검사, 구조 분석, 본문 추출, 표/셀/문자열 안전 편집을 수행하는 학습용 MCP Server (`hwp-editor-mcp`) 구축 |
| **이유** | LLM 기반 클라이언트가 HWPX 문서를 안전하고 정교하게 조작할 수 있도록 모듈화된 MCP 도구 제공 |
| **예시** | `inspect_document`, `extract_text`, `fill_cells`, `replace_text` 등의 MCP Tool 제공 |
| **위반 시** | 허용되지 않은 HWPX 원본 직접 덮어쓰기 금지, 작업 루트 외 접근 금지 |

## 완성 기준 (Definition of Done)
| 항목 | 내용 |
|---|---|
| **규칙** | README 명시 5단계 기능 요구사항 완료 및 `uv run pytest` 테스트 전체 통과 |
| **이유** | 신뢰할 수 있는 MCP Server 동작 보장 및 리그레션 방지 |
| **예시** | 모든 단위/통합 테스트 Pass, HWPX 생성 파일 재검증 통과 |
| **위반 시** | 테스트 미통과 또는 재검증 실패 시 기능 완료 처리 불인정 |

## 마일스톤 계획
| 항목 | 내용 |
|---|---|
| **규칙** | 1단계(샘플 3종 검증) -> 2단계(문단 추가 Tool) -> 3단계(표 편집 OWPML 설계) -> 4단계(HWP 변환 어댑터) -> 5단계(Streamable HTTP/인증) 순차 진행 |
| **이유** | 핵심 리더 및 파싱 안정성 확립 후 고급 편집/연동 기능 추가 |
| **예시** | 각 단계별 단위 테스트 및 문서 검증 완료 |
| **위반 시** | 이전 단계 미검증 상태에서 후속 구현 진입 지양 |

## 일정 및 팀 역할
| 항목 | 내용 |
|---|---|
| **규칙** | 데드라인: 이번 주말 내 (2026-07-26 일요일까지). 전체 팀 프로젝트 중 HWP/HWPX MCP Server 모듈 단독 담당 |
| **이유** | 전체 팀 시스템 결합 일정 준수 |
| **예시** | 모듈 독립성 유지 및 약속된 MCP 스키마 준수 |
| **위반 시** | 핵심 스키마 변경 시 팀원 사전 공유 |
