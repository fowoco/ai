# 보안 컨벤션

## HWPX 파일 및 경로 보안
| 항목 | 내용 |
|---|---|
| **규칙** | 1) 원본 HWPX 파일 덮어쓰기 절대 금지 2) 작업 루트 (`HWP_MCP_ROOT`) 외 상위 디렉토리 트래버스(`..`) 및 경로 탈출 금지 |
| **이유** | 원본 문서 파손 방지 및 디렉토리 트래버스 공격을 통한 시스템 무단 접근 차단 |
| **예시** | `target_path.resolve().is_relative_to(allowed_root)` 파이썬 경로 검증 |
| **위반 시** | `HwpxSecurityError` 발생 및 작업 중단 |

## XML 및 파싱 보안
| 항목 | 내용 |
|---|---|
| **규칙** | HWPX 내부 XML 읽기 시 파이썬 기본 `xml.etree` 대신 반드시 `defusedxml` 사용 |
| **이유** | XXE(외부 엔티티 참조) 공격 및 Zip Bomb 등 XML 보안 취약점 차단 |
| **예시** | `import defusedxml.ElementTree as ET` |
| **위반 시** | 검증되지 않은 원시 파서 사용 금지 |

## 개인정보 보존 정책
| 항목 | 내용 |
|---|---|
| **규칙** | HWPX 양식 프로필(Form Profile) 저장 시 구조 지문만 남기고 성명, 전화번호, 주소 등 개인정보 포함 금지 |
| **이유** | 개인정보 유출 방지 및 양식 프로필의 안전한 재사용성 보장 |
| **예시** | `label: "성명"`만 저장하고 `value: "홍길동"`은 저장하지 않음 |
| **위반 시** | 프로필 검증 시 민감 정보 포함 시 저장 차단 |
