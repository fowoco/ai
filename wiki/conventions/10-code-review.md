# 코드리뷰 체크리스트

## 셀프 리뷰 및 PR 점검 항목
| 항목 | 내용 |
|---|---|
| **규칙** | PR 생성 전 셀프 점검: 1) `uv run pytest` 전체 통과 2) HWPX 원본 보존 및 허용 경로 (`HWP_MCP_ROOT`) 상위 디렉토리 이탈 방지 3) `defusedxml` 파싱 안전성 및 Pydantic 스키마 검증 |
| **이유** | 결함이 포함된 코드의 main 브랜치 유입 사전 차단 및 보안 안정성 보장 |
| **예시** | PR 템플릿 내 [x] pytest 통과, [x] 원본 보존 확인 체크 |
| **위반 시** | 체크리스트 미충족 PR merge 불가 |

## 자동 검증 항목
| 항목 | 내용 |
|---|---|
| **규칙** | CI/자동화 환경에서 테스트 실행 및 린트 검사 통과 필수 |
| **이유** | 인간의 검토와 별개로 기계적 불변 규칙 자동 검증 |
| **예시** | `uv run pytest` 자동 연동 |
| **위반 시** | 빌드 실패 시 리뷰 진행 보류 |
