# HITL 리스크 기준

## HIGH 리스크 (사용자 명시적 승인 필수)
| 항목 | 내용 |
|---|---|
| **규칙** | HWPX Edit Plan 실물 문서 적용 (`apply_edit_plan`), 출력 파일 최종 저장, 원본 파일 경로 수정, 주요 스키마 호환성 변경 |
| **이유** | 문서 훼손 및 의도치 않은 데이터 치환/파괴 조치 방지 |
| **예시** | Agent가 Edit Plan 미리보기를 제공하고 사용자 승인 버튼 클릭 후 파일 생성 |
| **위반 시** | 사용자 명시적 승인 없이 `apply_edit_plan` 자동 실행 절대 금지 |

## MEDIUM 리스크 (비동기 알림 및 주의)
| 항목 | 내용 |
|---|---|
| **규칙** | `rhwp` 렌더링 시각 비교에서 미세 비주얼 diff 발생, pytest 경고 발생, 양식 프로필 미치환 후보 감지 |
| **이유** | 이상 징후 조기 포착 및 레이아웃 붕괴 주의 환기 |
| **예시** | "⚠️ 변경 후 텍스트 넘침 위험 감지됨" 알림 표시 |
| **위반 시** | 경고 발생 시 무시하고 자동 적용 진행 금지 |

## LOW 리스크 (자동 승인 / 즉시 수행)
| 항목 | 내용 |
|---|---|
| **규칙** | 문서 검사 (`inspect_document`), 텍스트 추출 (`extract_text`), 미리보기 PNG 생성, devlog/wiki 문서 작성 |
| **이유** | 읽기 전용 작업 및 안전한 부작용 없는 조회의 개발 생산성 유지 |
| **예시** | `inspect_document` 호출 시 자동 승인 실행 |
| **위반 시** | 단순 읽기 작업에 불필요한 사용자 승인 팝업 요청 지양 |
