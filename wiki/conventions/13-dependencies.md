# 의존성 관리

## 패키지 설치 및 관리 도구
| 항목 | 내용 |
|---|---|
| **규칙** | 파이썬 의존성 추가/삭제 시 `uv` 사용 (`uv add <package>`). `pyproject.toml`과 `uv.lock`을 반드시 동기화하여 버전 제어 |
| **이유** | 재현 가능한 패키지 빌드 및 개발 환경 간 일관성 유지 |
| **예시** | `uv add defusedxml` |
| **위반 시** | `uv.lock` 누락 상태 커밋 금지 |

## 신규 의존성 도입 정책
| 항목 | 내용 |
|---|---|
| **규칙** | 새로운 외부 패키지 도입 시 라이선스 및 안전성 확인 후 팀원 사전 공유 |
| **이유** | 무분별한 의존성 증가(Bloatware) 및 보안 취약 패키지 유입 방지 |
| **예시** | PR 설명에 새로 도입하는 라이브러리 및 사유 명시 |
| **위반 시** | 검증되지 않은 패키지 임의 추가 금지 |
